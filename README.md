# embedded-study

방산·임베디드 SW 신입 취업을 목표로 한 12주 학습 기록입니다.
매일 공부한 내용을 내 말로 정리하고, 직접 짠 실습 코드를 올립니다.

## 학습 환경
- 보드: STM32 Nucleo-F411RE (Cortex-M4, ST-Link 내장)
- 도구: STM32CubeIDE, VS Code, WSL2(Ubuntu), gcc, Git
